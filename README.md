# NonDesigner – Documentation for the PrestaShop 2D graphic designer module

**NonDesigner** is a **PrestaShop module** that adds a **2D graphic designer** (product customizer / editor) to the product page. Customers add text, images, shapes, fonts and QR codes to personalize products online, and for every order the module automatically generates **print-ready files: vector SVG and 1:1 PNG**, available in the PrestaShop Back Office.

This repository contains the **public user guide and configuration manual** of the module.

- Official website: [nondesigner.com](https://www.nondesigner.com/)
- Live demo: [nondesigner.com/demonondesigner/](https://www.nondesigner.com/demonondesigner/)
- Buy on PrestaShop Addons: [NonDesigner – 2D graphic designer for custom products](https://addons.prestashop.com/en/product-variants/99215-nondesigner-2d-graphic-designer-for-personalised-products.html)
- Developer: [Media Web](https://www.mediaweb-x.com/)

## At a glance

- Compatible with PrestaShop 1.7.6.1 to 8.x and 9.x; PHP 7.2 to 8.5.
- 2D design area with text, images, shapes, layers, QR codes, photo filters and effects.
- Print-ready vector SVG and 1:1 PNG files for every order.
- Front/back printing, bleed margin, rectangular or round shapes, rounded corners.
- Fonts served locally from your own server (no external font loading).
- Native PrestaShop Multistore support. No license activation required.
